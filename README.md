# sysfetch

Sysfetch is a neofetch inspired tool for displaying system information.  Sysfetch is written in C# and supports .NET 7.0 on Windows, Linux and MacOS.  Sysfetch does not support all of the same features of neofetch and is not intended to be a replacement.

Key features

* Runs natively on Windows, Linux and MacOS.
* Data can be exported to a file (TODO)
